# Login Page - Test Scenarios

These are illustrative practice scenarios, not results from
testing a live application.

1. Verify login with valid credentials.
2. Verify login with an invalid username.
3. Verify login with an invalid password.
4. Verify login with both fields empty.
5. Verify login with only the username entered.
6. Verify login with only the password entered.
7. Verify password masking.
8. Verify the Forgot Password link.
9. Verify validation messages.
10. Verify login using the Enter key.
