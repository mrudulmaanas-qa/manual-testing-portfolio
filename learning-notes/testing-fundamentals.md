# Software Testing Fundamentals

## SDLC
Software Development Life Cycle.

## STLC
Software Testing Life Cycle.

## Smoke Testing
A preliminary check to verify that the major functions
of a build work.

## Sanity Testing
A focused check to verify that a particular change
or functionality works as expected.

## Regression Testing
Testing existing functionality after changes to ensure
that previously working features are not affected.

## Retesting
Testing a specific defect again after it has been fixed.

## Severity
The impact of a defect on the application.

## Priority
How urgently a defect should be fixed.
