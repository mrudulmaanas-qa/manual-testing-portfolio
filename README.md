# Manual Testing Portfolio

A personal portfolio documenting my Software Testing training,
manual testing concepts, test case design, and practical exercises.

## Skills and Topics
- SDLC and STLC
- Functional Testing
- Smoke and Sanity Testing
- Regression and Retesting
- Equivalence Partitioning
- Boundary Value Analysis
- Defect Life Cycle
- Test Case Design
- Bug Reporting

## Repository Structure

- test-plans/ - Practice test plans
- test-cases/ - Test cases and test data
- test-scenarios/ - Application test scenarios
- bug-reports/ - Sample defect reports
- checklists/ - Testing checklists
- learning-notes/ - Testing concepts and notes

## About
This repository contains learning exercises and practice work
completed as part of my Software Testing training.
